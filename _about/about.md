# About Me - Liang

I'm Liang, a developer who builds at the intersection of backend engineering, workflow automation, and creative technology. My background spans VFX pipeline tooling, AI-assisted production, and indie SaaS — work that tends to live where technical depth meets domain-specific constraints.

# What I Do

### Pipeline Tooling and Workflow Automation
I design and build tools that make complex production workflows reliable and repeatable. That includes backend systems, batch processing pipelines, and domain-driven architectures that hold up when the constraints get messy. My Houdini pipeline work — scripting, node automation, headless rendering — comes from doing this in a real production environment.

### Backend Engineering
I specialize in backend systems that are maintainable and composable: clean domain models, thoughtful API design, sensible infrastructure choices. I've integrated travel agency ticketing APIs, built ERP systems from scratch, and rebuilt aging systems that had grown too fragile to extend.

### AI Tools and Agentic Development
I've been working with AI coding tools for a while, and I care about where they actually help versus where they add noise — particularly in domain-specific contexts like VFX pipelines where the training data thins out fast. My [writing on this](https://liangyu.dev/posts) tries to be concrete and honest rather than promotional.

### Creative Technology
My background in animation production — including rigging work for a Disney Jr. series — gives me fluency in both the creative pipeline and the tooling that supports it. That cross-disciplinary perspective shows up in how I approach problems: I think about the person using the tool, not just the system running it.
