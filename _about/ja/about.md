# プロフィール - Liang

Liang です。バックエンドエンジニアリング、ワークフロー自動化、クリエイティブテクノロジーが交わる領域でものづくりをしている開発者です。VFX パイプラインツール、AI を活用した制作、個人開発の SaaS など、技術的な深さと領域固有の制約が重なる場所での仕事を続けてきました。

# やっていること

### パイプラインツールとワークフロー自動化
複雑な制作ワークフローを、安定して再現できるものにするためのツールを設計・開発しています。バックエンドシステム、バッチ処理パイプライン、そして制約がややこしくなっても破綻しないドメイン駆動のアーキテクチャなどです。Houdini パイプラインの仕事——スクリプト、ノードの自動化、ヘッドレスレンダリング——は、実際の制作現場での経験から来ています。

### バックエンドエンジニアリング
保守しやすく、組み合わせやすいバックエンドシステムを得意としています。きれいなドメインモデル、よく考えられた API 設計、無理のないインフラ選定。旅行代理店の発券 API との連携、ゼロからの ERP 構築、もろくなって拡張できなくなった古いシステムの作り直しなどを手がけてきました。

### AI ツールとエージェント型開発
AI コーディングツールはしばらく使い込んでいて、本当に役立つ場面とノイズを増やすだけの場面の見極めを大事にしています。特に VFX パイプラインのように、学習データがすぐに薄くなる領域ではなおさらです。[このテーマの記事](/ja/posts)では、宣伝ではなく具体的で正直な内容を心がけています。

### クリエイティブテクノロジー
Disney Jr. のシリーズでのリギングを含むアニメーション制作の経験があり、クリエイティブなパイプラインとそれを支えるツールの両方に通じています。この分野横断の視点は問題への向き合い方にも表れていて、システムだけでなく、ツールを使う人のことを考えるようにしています。

# アニメーションからのインスピレーション

アニメーションは幅広いスタイルと物語が好きです。Pixar の『トイ・ストーリー』や宮崎駿の世界からは創作の燃料をもらい、物語と美意識への感覚を育ててもらいました。一方で、型破りな作品にも惹かれます。『ねこぢる草』、『オーバー・ザ・ガーデンウォール』、『Smiling Friends』。物語の枠を押し広げる作品は、面白い技術の仕事が決して技術だけで完結しないことを思い出させてくれます。
